# Instrucciones de trabajo

## Registro de decisiones y cambios

La usuaria solicita mantener `Decisiones.md` actualizado con todas las decisiones tomadas y todos los cambios ejecutados desde el 13 de octubre de 2026.

- Leer el registro al iniciar una tarea y agregar una entrada al terminar cada conjunto de cambios.
- Registrar la fecha, las decisiones y sus motivos, los archivos modificados, las verificaciones y los pendientes o bloqueos.
- Mantener las entradas anteriores y distinguir acciones ejecutadas de propuestas.
- Incluir la actualización del registro en el mismo commit que los cambios de la tarea.
- No registrar secretos ni datos confidenciales.

## Colaboración mediante Git

La usuaria autoriza realizar commits y push de los avances de este proyecto para que sus compañeros puedan seguirlos en el repositorio compartido.

- Revisar el estado del repositorio y los cambios antes de cada commit; incluir únicamente los archivos correspondientes a la tarea.
- Usar mensajes de commit claros y conservar la identidad de Git configurada.
- Verificar el resultado del push e informar si los cambios quedaron locales por un problema de permisos, autenticación o conexión.
- Si el remoto tiene cambios nuevos, integrarlos sin sobrescribir el trabajo de otros. No hacer force push ni descartar cambios ajenos.
- Esta autorización corresponde a compartir el código en Git; la publicación de la web sigue las instrucciones de revisión del proyecto.
